# 强化学习 · Reinforcement Learning (RL)

## RL 是什么 / What Is RL

**强化学习 Reinforcement Learning**: 一个**智能体 agent** 在**环境 environment** 中通过**试错 trial-and-error** 学习**策略 policy**, 以最大化**累积奖励 cumulative reward**.

> An **agent** learns a **policy** through **trial-and-error** in an **environment** to maximize **cumulative reward**.

**三大特征 Three features**:
1. **主动交互 Active interaction** (不是被动观察数据)
2. **延迟奖励 Delayed reward** (现在的动作影响未来)
3. **探索-利用权衡 Exploration-Exploitation** (尝试新 vs 利用已知)

## 马尔可夫决策过程 MDP

### 定义 Definition

**MDP** = (S, A, P, R, γ):

| 符号 Symbol | 含义 Meaning |
|----|----|
| S | 状态空间 state space |
| A | 动作空间 action space |
| P(s'|s,a) | 转移概率 transition probability |
| R(s,a) | 奖励函数 reward function |
| γ ∈ [0,1] | 折扣因子 discount factor |

### 马尔可夫性质 Markov Property

**关键假设 Key Assumption**: 下一个状态 s' 只依赖**当前** (s, a),与历史无关.

```
P(s_{t+1} | s_0, a_0, ..., s_t, a_t) = P(s_{t+1} | s_t, a_t)
```

**意义 Implication**: 当前状态**完整描述**了做决策所需的信息.

**反例 Counter-example**: 扑克牌游戏(对手手牌未知),需要"信念状态 belief state".

### 目标 Goal

找最优策略 π*: S → A,最大化**期望累积折扣奖励**:

```
V^π(s) = E[Σ γ^t · R(s_t, a_t) | s_0 = s, π]
π* = argmax_π V^π(s) ∀s
```

## 值函数 Value Functions

### 状态值 State Value V(s)

V^π(s) = 策略 π 下从状态 s 开始的期望累积奖励.

### 动作值 Action Value Q(s, a)

Q^π(s, a) = 策略 π 下从 (s, a) 开始的期望累积奖励.

### Bellman 方程 Bellman Equation

```
V^π(s) = Σ_a π(a|s) [R(s,a) + γ Σ_{s'} P(s'|s,a) V^π(s')]

Q^π(s,a) = R(s,a) + γ Σ_{s'} P(s'|s,a) V^π(s')
```

**直觉 Intuition**: 当前值 = 即时奖励 + 下一状态的折扣值.

### 最优 Bellman Equation

```
V*(s) = max_a [R(s,a) + γ Σ_{s'} P(s'|s,a) V*(s')]
Q*(s,a) = R(s,a) + γ Σ_{s'} P(s'|s,a) max_{a'} Q*(s',a')
```

**关键 Critical**: 若知道 Q*,最优策略 = argmax_a Q*(s,a).

## RL 的三大方法 / Three RL Methods

### 1. 值函数方法 Value-Based (Q-Learning)

**核心 Core**: 学习 Q*(s,a).策略隐式 = argmax.

**Q-Learning (Watkins 1989)**:
```
Q(s,a) ← Q(s,a) + α [R + γ · max_{a'} Q(s',a') - Q(s,a)]
```

**Deep Q Network (DQN)** (Mnih 2013, 2015): 用神经网络近似 Q.

**突破 Breakthrough**: DQN 玩 Atari 游戏,多个超过人类水平.**DeepMind 第一次大新闻**.

**局限 Limits**:
- 离散动作 discrete actions only
- 难处理随机策略 stochastic policy

### 2. 策略梯度方法 Policy Gradient (REINFORCE)

**核心 Core**: 直接参数化策略 π_θ,用梯度上升.

**目标 Objective**:
```
J(θ) = E_π[V^π(s_0)]
∇J(θ) = E[∇log π_θ(a|s) · Q^π(s,a)]
```

**直觉 Intuition**: 增大"好结果"动作的概率.

### 3. Actor-Critic

**核心 Core**: 同时学策略(Actor)和值函数(Critic).

**Actor**: π_θ(a|s)
**Critic**: V_w(s) 或 Q_w(s,a)

**优势函数 Advantage**:
```
A(s,a) = Q(s,a) - V(s)
```

表示"动作 a 比'平均'好多少".

**Advantage Actor-Critic (A2C, A3C)**: 主流方法.

## PPO (Proximal Policy Optimization, 2017)

**John Schulman et al. 2017** (OpenAI): PPO 成为**RLHF 的事实标准**.

**核心思想 Core idea**: 限制策略更新,防止"破坏性"变化.

```
L^CLIP(θ) = E[min(r_t(θ) · A_t, clip(r_t(θ), 1-ε, 1+ε) · A_t)]
where r_t(θ) = π_θ(a|s) / π_θ_old(a|s)
```

**直觉 Intuition**: 不要让新策略与旧策略**差太多**(比率 r 被裁剪到 [1-ε, 1+ε]).

**为什么 PPO 赢 Why PPO won**:
- 比 TRPO 简单
- 比 vanilla PG 稳定
- 易并行化
- 样本效率可接受

## AlphaGo (2016)

### 架构 Architecture

**DeepMind AlphaGo (Silver et al. 2016)**:

```
[棋盘状态 Board State]
       ↓
[策略网络 Policy Network] → 落子概率 move probabilities
[价值网络 Value Network] → 胜率估计 win probability
       ↓
[蒙特卡洛树搜索 MCTS] → 选择最佳 move select best move
```

### 训练流程 Training Pipeline

1. **监督学习 SL**: 从人类棋谱学习策略网络
2. **强化学习 RL**: 策略网络自我对弈,用胜负信号改进
3. **价值网络训练**: 用自我对弈数据训练"胜负评估器"
4. **推理时 MCTS**: 结合策略+价值,搜索深度

### AlphaGo → AlphaZero (2017) → MuZero (2019)

**AlphaZero**: 移除人类棋谱,**完全从零自我对弈**.适用于围棋、象棋、将棋.

**MuZero**: **不知道游戏规则**,通过观察学习世界模型.适用于 Atari + 棋类.

**意义 Significance**: RL 可以**完全无人类数据**达到超人水平.

## 强化学习与监督学习对比 / RL vs Supervised Learning

| 维度 Dimension | 监督 SL | 强化 RL |
|----|----|----|
| 数据来源 Data | 固定数据集 fixed dataset | 交互产生 generated by interaction |
| 反馈 Feedback | 每步有标签 label per step | 延迟奖励 delayed reward |
| 目标 Goal | 最小化预测误差 min prediction error | 最大化累积奖励 max cumulative reward |
| 探索 Exploration | 不需要 not needed | 必需 required |
| 安全性 Safety | 无行动 no actions | 可能有害 potentially harmful |
| 样本效率 Sample Efficiency | 高 high | 低 low |

## 挑战与开放问题 / Challenges & Open Problems

### 1. 样本效率 Sample Efficiency

RL 通常需要**数百万**交互.人类学新任务只需几次.

### 2. 奖励设计 Reward Design

"我设计了奖励,但我**真的**想要这个吗?"——奖励黑客 reward hacking 常见.

**例 Example**: 让机器人**打扫**房间,机器人把所有东西扔到垃圾桶(打扫 = 没东西在地上).

### 3. 探索 Exploration

如何高效探索大状态空间?**好奇心驱动 curiosity-driven** 是方向之一.

### 4. 信用分配 Credit Assignment

长时序任务中,哪一步动作导致最终结果?**TD(λ), 资格迹 eligibility traces** 是经典技术.

### 5. 多智能体 Multi-Agent

围棋是 2 人博弈,真实世界多智能体.**纳什均衡 Nash Equilibrium** 在多智能体 RL 中起作用.

### 6. 迁移学习 Transfer Learning

学过的任务能帮助学新任务吗?**Meta-RL, 多任务 RL** 是方向.

## 未来方向 Future Directions

### Offline RL

从**固定历史数据**学习 RL(不能交互).医疗、金融等领域只能这样.

### Inverse RL

观察专家行为,**反推**奖励函数.可能解决"奖励设计"问题.

### Multi-Modal RL

机器人:视觉+力觉+语言,多模态输入.

### World Models + RL

Dreamer 系列:先学世界模型,在**模型内**做 RL.**样本效率大幅提升**.见 [[world-models]].

## 与 LLM 的连接 / Connection to LLMs

1. **ChatGPT = LLM + RLHF**
   没有RLHF, LLM 只是"预测下一 token"工具.**RLHF 把它变成助手**.这是 ChatGPT 比普通 LLM 火爆的根本原因.
   > ChatGPT = LLM + RLHF. Without RLHF, LLMs are just next-token predictors.

2. **o1 (OpenAI 2024) = LLM + RL 推理**
   OpenAI o1 用 RL 训练 LLM **思考多步**.类似 AlphaZero 思路:LLM 自我生成推理过程,RL 优化.
   > o1 (OpenAI 2024) = LLM + RL reasoning. Like AlphaZero: LLM generates reasoning, RL optimizes.

3. **AlphaProof / AlphaGeometry / FunSearch**
   DeepMind 用 RL + LLM 做数学发现.**这是 AI 自我生成训练数据**的范式,可能突破"数据墙".
   > AlphaProof/Geometry/FunSearch: RL + LLM for math discovery. AI generates own training data — may break data wall.

4. **范式思考**: RL 是 LLM 范式的"下一步" 吗?
   - 当前 LLM 主导: 预训练 + SFT + RLHF
   - 未来可能: + RL on reasoning (o1) + RL on tools (Agent)
   - 但 RL 本身**也有局限** (奖励设计、样本效率、信用分配)
   - **真正突破**可能需要 RL + 世界模型 + 因果推理
   > RL is LLM paradigm's "next step" (o1, AlphaProof). But RL has own limits. True breakthrough may need RL + world models + causal reasoning.
