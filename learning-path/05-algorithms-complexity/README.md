## 关键问题 / Key Questions

1. 快速排序平均 O(n log n),但最坏 O(n²). 为什么实际仍用它? / Quicksort avg O(n log n), worst O(n²). Why use it?
2. 哈希表平均 O(1),最坏 O(n). 最坏情况什么时候发生? / Hash table avg O(1), worst O(n). When does worst happen?
3. P = NP 吗?为什么这个问题如此重要? / Does P = NP? Why so important?
4. Transformer 的注意力机制 O(n²) 复杂度,如何优化? / Transformer attention O(n²), how to optimize?
5. "涌现能力 emergent ability"是真正的算法突破,还是规模扩展? / Is "emergent ability" real breakthrough or scaling?
