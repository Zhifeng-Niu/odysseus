## 3. 本次基线的直接产出：一个真实生产 bug

第一次全失败（0/3）的根因不是模型——诊断轨迹显示模型完美完成任务，但
**file 工具把相对路径解析到了驱动进程的 process.cwd() 而不是 agent 的
ctx.cwd**，文件写进了仓库外，progress 层正确地判零进展并回滚。
脚本化测试看不见它（脚本 provider 用绝对路径）——这正是真实基线的价值。

修复：file 三工具按声明契约解析相对路径到 ctx.cwd（校验先于解析），
throwing verifier 计为 artifact-mismatch 而非套件崩溃。
commits：66a61ff（修复）+ 89b7c0d（harness 容错）。
